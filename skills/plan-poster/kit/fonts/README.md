# 字体来源

| 字体 | 用途 | 许可 | 来源 |
|---|---|---|---|
| 得意黑 Smiley Sans (Oblique) | 海报标题 | SIL Open Font License 1.1 | https://github.com/atelier-anchor/smiley-sans |

OFL 允许自由使用/嵌入/再分发（含商用），要求保留版权声明、不得单独售卖字体本身。
因此 woff2 随 skill 入库，用于本地渲染。

正文与英文**不打包字体**，走系统栈（`PingFang SC` / `Poppins` / `Avenir Next`）：
中文字库动辄 20MB 起，为正文打包不划算，且下载常超时。
